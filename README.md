# 手で描く

カメラに手を映すと、AIが指の位置を読み取り、親指と人差し指をつまむと空中に線が描けるページです。

- つまむ … 線を描く
- はなす … ペンを上げる
- グーを1秒 … 全部消す

映像は端末の中だけで処理され、外には送られません。

公開先: https://yannsi.github.io/te-de-egaku/

## 電波のない所で使う

手を読み取る部品（MediaPipe とモデル、十数MB）は外のサーバーから読み込みます。一度ネットのある所で「はじめる」を押すと、ページと部品が端末に保存され、次からは電波がなくても動きます（`sw.js`。空中ギター・紙のピアノも同じ部品を使うので、どれか1つで保存すれば3つとも動きます）。
